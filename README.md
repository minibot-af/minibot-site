# Mini Bot — سایت رسمی (معرفی)

سایت معرفی Mini Bot برای دامنه اصلی (مثلاً `web.minibot.online`): صفحه معرفی ربات، امکانات، مراحل کار، قیمت‌ها و سوالات پرتکرار، با دکمه‌های شروع که به پنل کاربران می‌روند.

ساختار:
- `public/index.html` — سایت کامل (تک‌فایل، فارسی/RTL، بدون وابستگی)
- `wrangler.jsonc` — کانفیگ دیپلوی (کاملاً استاتیک، بدون Worker)

دیپلوی: مخزن را در داشبورد Cloudflare وصل کنید؛ دستور `npx wrangler deploy` همین کانفیگ را می‌خواند. سپس از تب Domains دامنه دلخواه (مثلاً `web.minibot.online`) را به Worker اضافه کنید.

آدرس پنل کاربران و پنل مدیریت در ابتدای اسکریپت انتهای `index.html` در ثابت‌های `PANEL_URL` و `ADMIN_URL` تعریف شده؛ برای تغییر فقط همان دو خط را عوض کنید.
